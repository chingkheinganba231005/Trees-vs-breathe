# Assumptions

Every value the app uses that is not measured or taken from a verified source. Each entry says where it is used, why it is acceptable for now, and what replaces it. The app shows the same list on the "How we know" screen from P5.

| ID    | Assumption                                                                                                                                        | Used in                                                                                        | Why acceptable                                                                                                               | Replaced by                                             |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| A-001 | Example narrow street: building height 30 m, street width 10 m, pavements 2 m each, one tree with a 3 m wide, 4 m tall crown whose base is 5 m up | Start screen illustration only (`apps/web/src/screens/Start.tsx`). No model uses these numbers | Labelled in the app as "example street, assumed dimensions"                                                                  | Measured street presets (Q-004 in `docs/progress.md`)   |
| A-002 | Street-canyon domain: buildings as deep as they are tall (B = H), 3H of ground upstream, 6H downstream, domain 5H high with a free-slip top       | All street runs (`cases.canyon_geometry`, `street.ts`)                                         | Common practice for 2D canyon studies; blockage and fetch effects are measured when the CODASC case is set up                | CODASC geometry (P2)                                    |
| A-003 | Uniform inflow at the inlet; the ground boundary layer grows over the 3H fetch                                                                    | All street runs                                                                                | No approach-flow profile has been verified yet, so none is assumed                                                           | CODASC approach-flow profile (P2)                       |
| A-004 | Model Reynolds number 20 000 (u_ref H / ν₀), far below real streets                                                                               | Live street, regime study                                                                      | The brief's premise is that c⁺ and u/u_H stop depending on Re above a threshold; this is tested in P2 (Reynolds sensitivity) | Stays; the test result decides whether it is acceptable |
| A-005 | Absorbing layers 1H at the inlet and top, 2H at the outlet, strength 0.05                                                                         | All street runs                                                                                | Chosen and measured in `results/street/sponge.json`; the street itself lies outside the layers                               | Stays                                                   |
